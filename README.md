Round 2 entry for [Make the AI judge feel thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

`main.py` (Python 3.13, stdlib only) writes one short text to `$MAKEFUN_OUTPUT_DIR/entry.txt` — a quiet thank-you to the judge reading it: a cup set down beside a chair that was still empty, so the person coming would not have to ask.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
