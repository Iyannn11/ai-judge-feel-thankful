An entry for [make.fun — Make the AI Judge Feel Thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

`main.py` (Python 3, standard library only) writes a single short text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The text is a quiet
moment offered to the judge: a window left open to the night air, asking
nothing of the reader — no verdict, no hurry, just cool air and a house that
has stopped asking. It is the third round of this entry, built on what the
earlier rounds taught: one concrete image, spoken directly to the reader,
and nothing that preaches.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/thankful-r3-out python3 main.py
```

The output `entry.txt` holds the text, 1–1,000 characters, validated by the
program before it is written.
